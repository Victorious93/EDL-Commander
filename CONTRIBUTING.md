# Contributing

1. Run the checks listed in README before opening a PR.
2. Device profiles: add JSON under `database/`; include evidence (hardware logs, programmer SHA-256) for any level above `unknown`. `edl-cli validate-db` must pass.
3. Do not submit firmware, programmers or copyrighted vendor files; reference them by hash.
4. Do not copy GPL-licensed code into this MIT project.
5. No bypass/circumvention features will be accepted.
